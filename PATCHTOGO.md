# About @patchtogo.ai/clsx

`@patchtogo.ai/clsx` is an unofficial fork of the npm package `clsx`, version 2.1.1, republished by [patchtogo](https://patchtogo.ai) with security fixes. patchtogo is not affiliated with the upstream authors, and all credit for the original code goes to them.

- Upstream package: https://www.npmjs.com/package/clsx
- Upstream source: https://github.com/lukeed/clsx at `925494cf31bcd97d3337aacd34e659e80cae7fe2`
- This fork: https://github.com/patchtogo-ai/clsx
